# 🛒 বাজার দর (BazarDor)

A modern web application designed to track and display real-time market prices of essential commodities (vegetables, fish, meat, rice, oil, etc.), compare current prices with previous weeks, and view district-wise price variations across Bangladesh.

---

## 🛠️ Technologies Used
- **Frontend Framework:** [Next.js](https://nextjs.org) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com)
- **Language:** TypeScript
- **Notifications:** React Toastify

---

## ✨ Key Features
1. **📊 Real-time Commodity Pricing:** View up-to-date daily market prices for essential items like vegetables, fish, meat, rice, and cooking oil.
2. **📈 Price Comparison:** Compare today's market rates with last week's prices to analyze inflation and market trends.
3. **🗺️ District-wise Price Tracking:** Check and compare how item prices vary across different districts in Bangladesh.
4. **🧭 Optimized Navigation (NavBar):** A fully responsive and dynamic custom navigation bar for seamless user experience.
5. **🔔 Interactive Feedback & Auth:** Secure user session management (Sign-out) with real-time notifications using `react-toastify`.
