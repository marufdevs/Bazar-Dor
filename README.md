# 🛒 বাজার দর (BazarDor)

A modern e-commerce and grocery web application built to make online shopping seamless and user-friendly.

---

## 🛠️ Technologies Used
- **Frontend Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Language:** TypeScript
- **Notifications:** React Toastify

---

## ✨ Key Features
1. **🚀 Optimized Navigation (NavBar):** A fully responsive and dynamic custom navigation bar for smooth user experience.
2. **🛍️ Single Product View:** Dedicated, clean layout and design for viewing individual product details.
3. **🔐 Secure Sign-Out:** Robust and secure user session management including sign-out functionality.
4. **🔔 Interactive Notifications:** Real-time feedback and alerts using `react-toastify` for user actions.
5. **⚡ Fast & Responsive Design:** Fully optimized layout across all devices built with Tailwind CSS and Next.js.
